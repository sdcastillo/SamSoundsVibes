Mission Control

Write one post. Publish sends it to Bluesky when this page is opened from the local server. The other accounts open a ready-to-send composer.

Run python3 publisher/server.py and open http://127.0.0.1:8787/. Bluesky connects with an app password from Bluesky settings, not your login password. X, Facebook, Instagram, LinkedIn, and YouTube do not accept a password from this app. They need a developer app on their site before a token can be stored. Substack and SoundCloud have no posting connection, so those still open in the browser.
