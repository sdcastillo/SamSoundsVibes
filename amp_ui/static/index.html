MIDI-style CC12/CC13 shown for reference (Kaoss/ZONA convention). Values drive the amp over WebSocket — no separate MIDI stack required. Hold freezes the last position.

Advanced (other interfaces / PipeWire)

Input auto-detect prefers Focusrite Scarlett Solo on ALSA (USB 1235:8211). Playback follows the system default PipeWire sink, so a plugged-in Logitech headset that is the default gets the guitar. If that sink is missing, playback falls back to Scarlett, then any other real output. Sliders update live while the amp runs. OBS can capture processed_guitar.monitor when PipeWire is available.
